# Git and GitHub Simulator

A C++ project that simulates Git and GitHub commands.

## Phase 1
- Virtual file system
- Repository initialization
- User configuration
- Staging area
- Commit
- Status
- Log

## Phase 2
- Branch
- Checkout
- Detached HEAD
- Diff
- Merge
- Conflict resolution
